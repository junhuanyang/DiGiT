# DiGiT

> **Coming soon.**

This repository will host the official implementation of **DiGiT**, a
diffusion-based modular geophysical toolkit for on-device multi-modal data
generation, presented in the following paper:

**DiGiT: A Diffusion-based Modular Geophysical Toolkit for On-device
Multi-modal Data Generation**

Junhuan Yang, Yuzhou Zhang, Yi Sheng, Youzuo Lin, Weiwen Jiang, and Lei Yang.

*ACM Transactions on Embedded Computing Systems*, 25(3):1--26, 2026.

The code and documentation will be released here.

## Related projects

DiGiT is built upon the following projects:

- [InversionNet / OpenFWI](https://github.com/lanl/OpenFWI)
- [Denoising Diffusion PyTorch](https://github.com/lucidrains/denoising-diffusion-pytorch)
- [Diffusion Distiller](https://github.com/Hramchenko/diffusion_distiller)

A related demo implementation is available in the
[SDC-DAC25 repository](https://github.com/Jqubcomp/SDC-DAC25). The complete
DiGiT implementation will be released in this repository.
